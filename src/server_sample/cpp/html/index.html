ログイン / 新規登録

ログインはユーザー名を空のままでもできます（端末に保存されたパスキーから選びます）。

承認待ちです

登録とログインはできていますが、スイッチを使うには、管理者に「許可」してもらう必要があります。 許可されると、このページを開いたままで使えるようになります。

メンバー

最初に登録した人は自動で管理者になります。2 人目からは、管理者が「管理者」か「一般」として許可するまで承認待ちです。 許可と、自分以外のアカウントの削除（承認待ちの人なら却下）は管理者だけができます。

サーバが保存しているもの

パスキー 1 つにつき、公開鍵とその付帯情報だけを保存しています。 顔や指紋のデータ、秘密鍵、パスワードは端末から出てこないので、ここにはありません。
