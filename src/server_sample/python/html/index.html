パスキー（WebAuthn）でログインして、自分のテナントの電気をオン・オフします。 テナントには、管理者から渡された URL（?tenant=…）を開いて参加申請します。

テナントのメンバー

このテナントの管理者は、参加申請を「管理者」か「一般」として承認したり、却下・外したりできます。

メンバーを招待

この QR コードか URL を渡してください。開いた人がログインして参加申請すると、ここに出てきます。

ログイン / 新規登録

ログインはユーザー名を空のままでもできます（端末に保存されたパスキーから選びます）。 最初に登録した人は全体の管理者になり、テナントを追加できます。

あなたのテナント

追加すると URL ができます。その URL をテナントの人に渡してください。 最初に参加申請した人が、そのテナントの管理者になります。

全体の管理者

全体の管理者の仕事

全体の管理者は、テナントの追加・削除、全体の管理者への申請の承認、アカウントの削除ができます。
